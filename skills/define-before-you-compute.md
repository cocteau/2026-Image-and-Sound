# Define before you compute

A question like "how many super PACs?" hides choices. Before computing, the
definition has to be written down in terms of actual columns and values.

When answering any question:

- State the definition in one sentence using real column names and values
  (e.g. "rows where CMTE_TP is O, U, V or W").
- If a word in the question could mean more than one thing ("new", "large",
  "primary"), say which meaning you chose and name the alternative.
- If you do not know what a code or column means, say so in `unsure` and point
  to where it is documented. Do not guess silently.
